Google Sheets Jobs: read-only linking inspection

Owner-only. This checks one manually selected J reference and row against the existing Jobs worksheet. Nothing is linked, booked, paid, saved to HQ, or written to Sheets.

For an existing J reference only. Matching-looking values are a review prompt, not proof of a historical link. No customer values are returned.

Only the selected row/reference eligibility is tested. Header checks cover a verified subset; they do not establish a trusted HQ identity mapping, approved baseline, consent to write, successful sync, payment receipt, or reconciliation. Any source conflict blocks linking.
