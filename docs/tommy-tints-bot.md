# Tommy Tints Bot mascot integration

Approved visual reference: Option 1, Tommy Tints Bot Concept Board, supplied by the owner 18 November 2026. Standalone transparent recreation keeps the cap, branded hoodie, chrome/black head, white smiling eyes, red trim/headphones and thumbs-up pose. All four optimised WebP variants derive from one image. Company logo and install icons unchanged.

Customer welcome is dismissible with a local preference only (no chat/customer data). Launcher stays outside the hidden intake steps; nonmodal conversation panel supports Escape, visible labels, keyboard focus, small screens and safe areas. One entrance tilt/reveal; no continuous animations. Anatomical waving, natural blinking and processing/reaction animations are deferred rather than faked on a static image.

Main currently has only the private HQ OpenAI assistant. It is NOT exposed publicly. The customer conversation is explicitly navigation-only with no free-text collection, API calls or pretend AI answers. Quote and booking buttons open the existing intake controls; shop link opens the real shop. On other pages the customer returns to Bookings for intake. Photo assessment, photo quality feedback, pricing, provider availability, trade acknowledgements, maintenance scheduling and automatic handover are unconnected. Do not claim these are operational. Product navigation does not claim recommendations.

Private HQ uses the small mascot next to its existing functional assistant, preserving owner authentication and behaviour. Before public OpenAI chat: implement a dedicated customer-safe backend with session isolation, abuse/rate and spend limits, privacy consent, vetted service/pricing context and tested approval gates; never reuse private HQ record tools/history for customers.
