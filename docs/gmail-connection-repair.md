19 November 2026: inspected main and merged PR #115. PR #115 discarded all provider reason details. Available filtered Railway runtime logs did not yield a specific reason. No messages were read/imported/sent in this investigation.

Confirmed callback defect: save_connection's False return (missing offline grant/storage unavailable) was ignored; a temporary in-memory token could be presented as success. Thus project/client identity, Gmail API enablement, actual Workspace restrictions and callback registration were NOT independently verified or changed.
